# MazeRunner v2 — дизайн и план (источник правды для rewrite/v2)

Заменяет REWRITE_PLAN.md. Решения принимает Claude (полная делегация от 2026-10-05).
Пользователь участвует только в финале: собирает APK, играет, выкладывает.

## Почему переделка

- 82 установки за 4 месяца → игру не видят; страница магазина (иконка, скриншоты) важнее кода.
- Тёмные серые коридоры от 3-го лица плохо читаются на скриншотах и на телефоне.
- Сдвиг стен сломан концептуально: стена едет вбок сквозь геометрию, `_grid` не обновляется,
  враги ходят по устаревшему графу, выход может стать недостижимым.
- Свет на КАЖДОЙ клетке (225–625 point lights), тысячи GameObject на стены.
- Три сложности + paywall на две из них = контента почти нет, платить не за что.

## Новая игра (концепция)

**Вид сверху под углом (~60°)**, тёмный лабиринт, свет только от факела игрока и светящихся объектов.
Сдвиг стен виден и понятен: за 2 с до сдвига пол подсвечивается (красным — тут вырастет стена,
бирюзовым — тут откроется проход), затем стены поднимаются/опускаются из пола.

- **Уровни, а не сложности.** Глава = 30 уровней, детерминированные по сиду. Кривая сложности:
  размер 6×6 → 18×18, интервал сдвигов, враги, ключ от ворот, радиус света.
- **3 звезды за уровень:** пройти · уложиться в «пар»-время · собрать все осколки.
- **Провал:** поймал враг или кончилось время (ворота закрываются на ночь — как в фильме).
- **Бонусы:** песочные часы (+время), кристалл (заморозка врагов). Модели уже есть.
- **Сдвиг всегда сохраняет проходимость** (swap-алгоритм на графе: открыть стену → закрыть ребро
  на образовавшемся цикле, не рядом с игроком/врагами).
- **Ежедневный лабиринт** — сид по дате, своя таблица рекордов (локально).
- **Главы:** 1 «Каменный лабиринт» (бесплатно), 2 «Канализация», 3 «Пески» — открываются
  покупкой `unlock_full` (старый product ID, старый ключ `FullUnlocked` уважается).
- Управление: плавающий джойстик в любой точке экрана, одним пальцем. Камера сама.

## Архитектура (`Assets/_Project`, namespace `MazeRunner`)

```
Core/      MazeData, MazeGen (seeded DFS + braid), MazePath (BFS), ShiftPlanner, LevelConfig, Rng
Game/      GameRoot (точка входа сцены), LevelController (state machine), MazeView (меши чанками),
           WallSlab, PlayerController, CameraRig, Enemy, Pickup, ExitGate, Joystick
Look/      Theme (данные глав), Lighting, Sfx
Meta/      Save (JSON в PlayerPrefs), Progress, Store (IAP)
UI/        UIKit (builder), экраны: Menu, Levels, Hud, Pause, Result, Unlock, Settings
Editor/    ProjectBuilder (сцены, build settings, иконки) — запускается batchmode,
           Shots (рендер скриншотов для проверки и для Play Market)
```

Переиспользуем: Player_Arissa.prefab (анимации StarterAssets), Spiders (враг), hourglass/crystal FBX,
аудио из Resources/Audio, текстуры Bricks075B, Sewer/Textures, Desert.
Старый код (Assets/Scripts, старые сцены) удаляется, когда v2 играбелен.

## Проверка без пользователя

Unity 6000.4.0f1 batchmode (Hub должен быть запущен/залогинен — лицензия Personal).
`-executeMethod MazeRunner.EditorTools.ProjectBuilder.BuildAll` — сцены + настройки.
`-executeMethod MazeRunner.EditorTools.Shots.Capture` — PNG скриншоты в scratchpad.
