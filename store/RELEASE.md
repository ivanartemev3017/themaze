# Как выпустить v1.0.0

Всё, что нужно сделать руками. Остальное уже в проекте.

## 1. Сборка (Unity)

1. Открой проект, ветка `rewrite/v2`.
2. **File → Build Profiles → Android** (должна быть одна сцена: `Assets/_Project/Scenes/Main.unity`).
3. **Player Settings → Publishing Settings**: keystore `themaze.keystore`, alias `themaze` — введи пароли.
4. Для теста на телефоне: сними галочку *Build App Bundle* → **Build** → установи `.apk`.
   Для Google Play: поставь галочку *Build App Bundle (Google Play)* → **Build** → получишь `.aab`.

Версия уже выставлена: **1.0.0**, versionCode **21**.

## 2. Что проверить на телефоне (10–15 минут)

- [ ] Меню открывается, за ним двигается лабиринт.
- [ ] Уровни 1–3: бежать пальцем удобно, камера не дёргается.
- [ ] Видно красные/синие полосы перед сдвигом, стены поднимаются/опускаются.
- [ ] Уровень 5+: паук гонится, если увидит; можно уйти за угол.
- [ ] Победа → звёзды → «Дальше» запускает следующий уровень.
- [ ] Кнопка «Назад» Android: в игре — пауза, в меню — выход.
- [ ] Звук есть, «Настройки» выключают звук.
- [ ] Яркость нормальная (не слишком темно).

Если что-то не так — опиши словами или скриншотом, я поправлю.

## 3. Google Play Console

1. **Внутреннее тестирование → Создать выпуск** → загрузи `.aab`.
2. **Страница в Google Play**: тексты — `store/LISTING.md`;
   иконка — `store/icon_512.png`; баннер — `store/feature_1024x500.png`;
   скриншоты — `store/screenshots_ru/` и `store/screenshots_en/` (5 штук, 1920×1080).
3. **Товары → Встроенные товары**: товар `unlock_full` уже должен быть. Проверь, что он *активен*
   (если его нет — создай с этим ID, разовая покупка). Цену можно оставить прежней.
4. Категория: **Головоломки**.
5. После проверки на внутреннем треке — продвинь выпуск в **Рабочую версию**.

## Важно

- `index.html` (политика конфиденциальности) лежит в ветке `main` — при слиянии `rewrite/v2` → `main` он сохранится (ветка уже содержит его).
- Старые покупатели `unlock_full` сохраняют доступ автоматически.
